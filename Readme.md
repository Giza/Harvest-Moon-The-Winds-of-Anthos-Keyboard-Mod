# Harvest Moon: The Winds of Anthos — Keyboard & Mouse Mod

Мод добавляет полноценную поддержку клавиатуры и мыши (включая управление камерой и навигацию по меню) в ПК-версию игры **Harvest Moon: The Winds of Anthos**.

---

## 🎮 Управление по умолчанию

### Игра (`Player`)

| Действие | Клавиша / Кнопка |
|---|---|
| Движение | `W` `A` `S` `D` |
| Взаимодействие / Подтвердить (A) | `E`, `Space` или **ЛКМ** |
| Отмена / Выбросить (B) | `Q` или **ПКМ** |
| Действия X / Y | `R` / `F` |
| Бег (удерживать) | `Left Shift` |
| Красться (удерживать) | `Ctrl` |
| Быстрые слоты | Стрелки |
| **Обзор камеры** | **Мышь** (или стрелки) |
| Приблизить / Отдалить камеру | `X` / `Z` |
| Сброс камеры / Вид сверху | `C` / `V` |
| Меню настроек / закрыть меню | `Esc` |
| Инвентарь (сумка) | `I` |
| Главное меню (DocPad) | `Tab` |
| Альбом / Настройки | `L` / `O` |
| Фото-режим | `P` |
| Debug-меню | `F1` |

### Меню (`UI`)

| Действие | Клавиша / Кнопка |
|---|---|
| Навигация | `W` `A` `S` `D` или стрелки |
| Подтвердить (`Submit`) | `Enter`, `E`, `Space` или **ЛКМ** |
| Отмена / Назад (`Cancel`) | `Esc`, `Q` или **ПКМ** |
| Дополнительные кнопки (X / Y) | `R` / `F` |
| Бамперы (`LB` / `RB`) | `[` / `]` |
| Триггеры (`LT` / `RT`) | `,` / `.` |

---

## ⚠️ Известные ограничения

- Курсор мыши не блокируется в центре экрана (`Cursor.lockState`), чтобы не ломать поведение игровых меню.
- Колесо мыши не задействовано по умолчанию (зум камеры назначен на клавиши).
